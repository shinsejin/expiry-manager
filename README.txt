유통기한 관리 앱 v1.2

[변경 사항]
- 카테고리 관리에서 ↑ / ↓ 버튼으로 순서 변경
- 변경한 순서는 메인 카테고리 필터와 상품 등록 선택 목록에 반영
- 카테고리 배열은 백업 파일에 포함되어 복원 가능

[실행 및 설치]
- index.html을 Chrome으로 열면 웹앱으로 사용할 수 있습니다.
- 홈 화면에 앱처럼 설치하려면 HTTPS 주소로 호스팅해야 합니다. GitHub Pages 등 무료 정적 호스팅을 이용할 수 있습니다.
- HTTPS 호스팅 후 Android Chrome 메뉴에서 '홈 화면에 추가' 또는 '앱 설치'를 선택하세요.
- 이 방식은 설치형 PWA이며 Play 스토어에서 받는 네이티브 APK와는 다릅니다.

[데이터]
- 데이터는 현재 브라우저/기기의 IndexedDB에 저장됩니다. 기기 변경 전 백업 파일을 내보내고 새 기기에서 복원하세요. 자동 동기화는 없습니다.
- 백업 파일에는 상품 정보, 사진, 카테고리와 카테고리 순서가 포함됩니다.
- 완전 종료 상태의 정시 알림은 지원하지 않습니다.
